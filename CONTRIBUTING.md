# Contributing to Hack the Booth

Thank you for helping build open, repairable DJ systems.

## Ways to contribute

- Improve documentation (English and Portuguese)
- Test controller compatibility
- Improve hardware design and printable parts
- Improve Linux audio and MIDI reliability
- Create workshop materials and examples

## Workflow

1. Open an issue describing the proposal.
2. Keep pull requests focused and small.
3. Include clear test or validation steps.
4. Update documentation when behavior changes.

## Quality expectations

- Prioritize accessibility and repairability.
- Avoid lock-in to proprietary tooling.
- Prefer open formats for hardware and documentation.
- Keep instructions reproducible on Raspberry Pi + Linux.

## Communication

Please follow the Code of Conduct in `/CODE_OF_CONDUCT.md`.
