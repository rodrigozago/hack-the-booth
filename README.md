# Hack the Booth

**Understand, modify and rebuild the DJ booth.**

Hack the Booth is an open-source project for understanding, modifying, and rebuilding DJ performance systems.

The first target device is a standalone Raspberry Pi system that allows USB DJ controllers that normally require a laptop to run independently.

## Vision

Hack the Booth connects electronic music culture with open hardware and software:

- Raspberry Pi
- Linux
- Mixxx
- MIDI and USB audio
- Touchscreens
- 3D printed parts
- DIY and repair-focused design

The project does **not** aim to replace DJ software. It aims to create open integrations that make DJ systems accessible, repairable, and hackable.

## Philosophy

Instead of closed ecosystems and disposable hardware, Hack the Booth promotes:

- openness
- repairability
- learning
- experimentation
- community
- accessibility

## Repository Structure

- `/docs` — project documentation, architecture, policies, and onboarding
- `/hardware` — electrical and mechanical hardware plans
- `/software` — software stack notes and future implementation modules
- `/manual` — bilingual end-to-end user manual (English + Portuguese)
- `/workshop` — workshop curriculum and delivery assets
- `/examples` — practical examples and sample configurations
- `/cad` — editable CAD source files
- `/stl` — printable STL exports
- `/scripts` — helper scripts for setup, diagnostics, and maintenance
