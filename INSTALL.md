# Installation (Initial Planning Guide)

This project is currently in architecture and documentation phase.

## Intended baseline target

- Raspberry Pi 4/5
- Raspberry Pi OS (64-bit)
- Mixxx
- ALSA/PipeWire stack
- USB DJ controller + USB audio interface

## Planned setup flow

1. Flash and boot Raspberry Pi OS.
2. Install Mixxx and audio dependencies.
3. Apply Hack the Booth audio + MIDI configuration.
4. Connect controller, audio interface, and touchscreen.
5. Launch booth UI and validate input/output routing.

Detailed, tested installation commands will be added as implementation matures.
