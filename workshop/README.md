# Hack the Booth: Build a Standalone DJ System

## Workshop goals

- Understand the architecture of a standalone DJ system
- Assemble a Raspberry Pi + controller + audio stack
- Configure Mixxx and MIDI mappings
- Practice troubleshooting in realistic scenarios

## Suggested schedule (1 day)

1. Intro and philosophy (30 min)
2. System architecture overview (45 min)
3. Hardware assembly activity (90 min)
4. Software setup and validation (90 min)
5. Troubleshooting exercises (45 min)
6. DJ performance demonstrations (60 min)
7. Wrap-up and contribution pathways (30 min)
