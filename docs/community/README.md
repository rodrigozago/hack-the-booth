# Community Model

Hack the Booth community is inspired by maker culture, Linux, repair culture, and electronic music.

## Participation areas

- Hardware builders
- Linux audio/MIDI contributors
- Workshop facilitators
- Technical writers and translators
- DJs and educators

## Community goals

- Lower barriers to standalone DJ systems
- Encourage learning through modification
- Share open designs and reproducible setups
- Build local workshops and knowledge hubs
