# License Recommendations

To align with openness and repairability, use a layered licensing model:

- **Software (`/software`, `/scripts`)**: MIT License
- **Documentation (`/docs`, `/manual`, `/workshop`)**: CC BY-SA 4.0
- **Hardware design files (`/hardware`, `/cad`, `/stl`)**: CERN-OHL-S v2

This combination supports remixing, commercial use, and reciprocity for hardware improvements.
